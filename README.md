
# Pawsitive Training - Dog Training App

A modern web application focused on dog training techniques for happier pets and owners.

## Project Overview

This dog training application features:
- Interactive 3D dog model with animations
- Training guides and tips
- Success stories from other dog owners
- Contact form for personalized training needs

## Getting Started

### Prerequisites
- Node.js & npm - [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating)

### Installation

```sh
# Step 1: Clone the repository
git clone <YOUR_REPOSITORY_URL>

# Step 2: Navigate to the project directory
cd pawsitive-training

# Step 3: Install dependencies
npm install

# Step 4: Start the development server
npm run dev
```

## Technologies Used

This project is built with:

- Vite
- TypeScript
- React
- shadcn-ui components
- Tailwind CSS
- Three.js (3D dog models)

## Features

- **Interactive 3D Dog Models**: Engage with animated dog models that respond to user interaction
- **Training Guides**: Access professional dog training techniques and methodologies
- **Quick Tips**: Practical advice for common dog behavior challenges
- **Success Stories**: Read about other owners' experiences with positive training methods
- **Responsive Design**: Works seamlessly on desktop and mobile devices

## Project Structure

- `/src/components` - React components including UI elements and 3D dog models
- `/src/pages` - Main page layouts and routes
- `/src/hooks` - Custom React hooks
- `/public` - Static assets including audio files and images

## Development

To run tests:
```sh

```

To build for production:
```sh
npm run build
```

## Deployment
